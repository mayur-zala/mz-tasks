## Tasks App

_Concept: frontend ↔ backend over HTTP. Data lives in-memory on the server._

**📘 Learn**

- **Angular (Mon–Wed):** clean project structure, routing, `HttpClient`, services
- **Backend (Thu–Sat):** Node + Express setup, REST routes, middleware (in-memory array, no DB yet)

**🔨 Build — Tasks App**

- Core:
  - [ ] Add a task (title)
  - [ ] View the list of all tasks
  - [ ] Toggle a task complete / incomplete
  - [ ] Delete a task
  - [ ] Empty state + loading state
- API: `GET /tasks` · `POST /tasks` · `PATCH /tasks/:id` · `DELETE /tasks/:id`
- Stretch: [ ] Filter All/Active/Completed · [ ] Inline edit title · [ ] "3 of 7 done" count

**Proves:** how a frontend and backend actually talk (HTTP, REST, JSON).
